# BeerMap: правила проекта

Карты «Де купити» для пивоварен и медоварен. **Один шаблон на всех клиентов.**
Общайся с владельцем по-русски; интерфейс карт на украинском. Длинное тире «—» не используем, только «–».

## Главное правило: новый клиент = данные, а не код

Новый клиент меняет ТОЛЬКО:
- `clients/<id>/client.json`: тексты, цвета, шрифт, форма маркера, страны, ссылка на таблицу;
- картинки в `clients/<id>/` (логотип, иконка «Що поруч», картинка «Ви тут»);
- свою Google-таблицу (точки продаж).

`template/` и `build/` общие. Нельзя копировать шаблон в папку клиента, делать «особую» версию
логики под одного клиента или класть туда `.js/.css/.html`: это ловит тест `tests/unit/guard.test.mjs`.
Если клиенту нужно что-то новое (форма маркера, картинка «Ви тут»), делаем это **опцией шаблона**
с умолчанием, которое не меняет других клиентов, и описываем в README.

## Как подключить клиента (делает Claude)

1. `npm run new-client -- <id> "<Название>" [--shape cap|hex|drop|honey] [--text XX]`: появится черновик (`"draft": true`).
2. Таблица: Drive `copy_file` шаблона «Шаблон: де купити (карта)» (id `1IliEW_BbXnSjlHprIyM8SJnWIa6FVmYhnqt6nv9ATe0`).
   Доступ: «Все, у кого есть ссылка: Читатель» (просит владелец) и «Редактор» для
   `beermap-bot@beermap-510413.iam.gserviceaccount.com` (Drive `share_file`).
   В `sheetCsvUrl`: `https://docs.google.com/spreadsheets/d/<ID>/export?format=csv`.
3. Точки вносить через Sheets-коннектор: колонки `name, type(shop/bar), city, street (с типом: «вулиця …»),
   house, old_street, instagram, gmaps_url, place_id, lat, lng, note, active(так/ні/пусто)`.
4. Бренд: логотип → `logo.jpg` 220px (ImageMagick `convert`), цвета с логотипа, подписи в `texts`.
5. Локально: `node build/build.mjs <id> --offline --csv tests/fixtures/<id>.csv ...` на тестовой таблице
   с примерными координатами (положить `tests/fixtures/<id>.csv`, CI подхватит сам), Playwright по всем клиентам.
6. Убрать `draft`, PR в `main`, после зелёного CI влить. Сборка сама найдёт координаты и карточки Google,
   впишет `place_id` в таблицу и опубликует `https://zhutler.github.io/BeerMap/<id>/`.
7. Прочитать сводку запуска: «проверь эти строки» (адрес не найден) и «карточки Google» (кандидаты со ссылками):
   решить с владельцем, вписать `place_id` / `lat,lng` в таблицу.

## Жёсткие требования (выстраданы, не нарушать)

- В браузере посетителя нет геокодинга: координаты только из сборки, карта открывается мгновенно.
- Геокодер в сборке: сначала заведение по названию (Nominatim POI) на нашей улице, потом адрес:
  Visicom → (MapTiler) → Nominatim; `street`, потом `old_street`. Принимаем только дом (или тот же номер
  без литеры) на нашей улице внутри bbox города; «центр города/улицы» отбрасываем. Не нашли: клиент не публикуется,
  в сводке список «проверь эти строки». Ручные `lat/lng` из таблицы главнее всего.
- Google: только `place_id`/ссылки для кнопки «Прокласти маршрут» (ведёт на карточку заведения).
  Координаты из Google на карту не берём.
- markercluster: `zoomSnap: 1`, целые зумы.
- Маска стран: Natural Earth `ne_10m_admin_0_countries_ukr` (с Крымом), +3 км, несколько стран сливаются.
- Мобилка в приоритете: шторка ~92px, плашка с лого, круглая кнопка геолокации; точки не прячутся под шторкой.
  Геолокация только с устройства, без установки точки тапом.
- «Що поруч»: в кадре человек и ближайший заклад (+ соседние, если почти так же близко); подсказка 7 с.
- Без бэкенда и платного хостинга. Публикация: GitHub Pages (основной, `*.pages.dev` блокирует провайдер Vega)
  и Cloudflare Pages параллельно.

## Процесс

- Изменения через ветку и PR в `main`; влить после зелёных «Проверок». Push в `main` запускает публикацию.
- Перед PR: `npm test` и Playwright по всем фикстурам:
  `for c in $(ls tests/fixtures/*.csv | xargs -n1 basename | sed 's/.csv$//'); do node build/build.mjs $c --offline --csv tests/fixtures/$c.csv --cache tests/fixtures/geocache.json --cities tests/fixtures/cities.json; done; npx playwright test`
- Баг из жизни → сначала тест, который его ловит (убедиться, что на старом коде падает), потом фикс.
- Сценарии людей: `tests/e2e/scenarios.spec.mjs` (фестиваль во Львове/Одессе, дома далеко от точек, отказ в геолокации, QR `?city=`).
- Из песочницы закрыты Google, Nominatim, Visicom, тайлы и сами сайты: живые проверки делает CI
  (сборка после публикации сама открывает сайт). Логи: GitHub MCP `get_job_logs`.

## Где что

- `template/` разметка, стили, логика карты; `build/` сборка, геокодер, карточки Google, публикация.
- `data/geocache.json`, `data/placeids.json`, `data/cities.json`: кеши, их коммитит CI. `data/masks/` контуры стран.
- Секреты GitHub: `VISICOM_API_KEY`, `GOOGLE_PLACES_API_KEY`, `GOOGLE_SERVICE_ACCOUNT_JSON`, `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`.
- Ссылка для QR на конкретный город: `https://zhutler.github.io/BeerMap/<id>/?city=Львів`.
